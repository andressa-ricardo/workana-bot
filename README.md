# Workana bot

<h3>In this project, you can log in to your workana account and send proposal to projects for a lot of peoples.</h3>

- In the first part of the application, a screen will open where you enter your credentials **(only accounts that were not created directly with Google, Facebook or Apple can use it)**

![](https://i.imgur.com/628JNg2.png)


**<h3>Technologies used:</h3>**
- Python
- Mysql
- Selenium
- Tkinter

**<h3>How to use: </h3>**

- `python -m venv venv`

- `source venv/bin/activate` # On Linux or macOS systems || `venv\Scripts\activate` # On windows system

- `pip install -r requirements.txt`

**<h3>Running the application:</h3>**

- `python .\main.py`
